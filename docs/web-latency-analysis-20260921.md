## 优化顺序

1. 预览与物品推理解耦：候选目标为5—10fps、有限显示尺寸、只保留最新帧，保持现有物品/行为推理频率。检测结果另显时间；不得将上一帧框无说明地贴到新帧上。断连、暂停、过期仍明确可见。实施后需测CPU、帧龄与用户交互延迟，不能直接把高频Streamlit整块刷新当作方案。
2. 统计采用增量汇总或数据库聚合，避免每5秒搬运并解析所有历史区间。必须保留跨日裁剪、时区、未知时长和活动区间更新语义；以现有逐行结果作为对照。
3. 对话无待处理请求时减少重复重绘；有请求时保留及时结果反馈。状态、历史、预览分别控制更新频率。
