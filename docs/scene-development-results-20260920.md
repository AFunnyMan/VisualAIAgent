# 2026-09-20 新视频检查与后续对比

用户补录后授权继续。新增两片可用，已继续比较R03/R04/R05并修复训练工具标签一致性检查。现阶段主要问题从困难手机漏检转为底部银白色物体触发的手机候选，尚不能默认替换正式模型。

## 素材

18-49-25约102.6秒为杯子，18-51-14约133秒为单手机。顺序解码6155/7980帧，均1920×1080、名义60fps；后一片容器估算7983帧，保留实际差异而不据此断言损坏。源SHA已冻结。

人工检查2秒概览及关键帧：杯有4次完整移出，手机有3次，其中第3次来自靠远桌沿豁免片段。手机适用完整移出计2次，豁免的1次不计成功也不计失败。杯开场已经在，手机末次放入后即结束，均不能算额外完整循环。另一个Sol在不查看模型结果的条件下独立审查人工区间通过；手机64—98秒是范围外episode，稳定在场实际66—96秒，此澄清未改变适用评分区间。

两片等待时间已够开发比较，无需重拍；但各只含一个类别，不能互作覆盖两类的开发版与验收版，也未达到各10次。需要正式验收时再另拍未用于选优的正常循环或现场操作，手机豁免情形不要求补录。瓶子继续免补拍。

## 实际对比

合此前4片，共6片401个1Hz输入，每个模型均使用相同输入和生产YoloOnnxDetector、杯缩放复查、0.35置信度及0.97近重复抑制。检测结果进入真实EventStateMachine（三次出现、五秒缺失）。这是按视频时间的离线回放，不是实时USB、MemoryStore证据写入/API联合或Windows验收。人工稳定区间先于推理冻结；所有素材仍为development，未用于训练/扫描epoch或阈值。原始final-test未读取。

- 杯长片：三个模型均在选定46个稳定在场采样检出杯，36个稳定无杯采样均无杯框；4次移出各4/4产生missing，没有额外杯事件。开场出现与4次返回均记录。类别在场计数不冒充逐帧框IoU准确率。
- 手机长片：三个模型都在6秒确认首次出现、23秒确认首次缺失、33秒确认再次出现；**第二次正常移出后47—64秒均没有产生missing**。该失败属于正常手机场景，不在用户豁免范围内。
- 关键混淆：长杯片仍不断输出手机框，三个模型各触发3次手机appeared；71采样空场片R04触发1次手机appeared与1次missing，R03/R05没有事件。可视化定位到画面最下方银白色物体露出的角。其真实类别已异步向用户询问，不能自行臆定为触控板/笔记本；原始候选与事件保留，不先作为确定类别标签训练。
- 手机稳定正常在场31采样，三模型类别检出均30，但底角框可能掩盖真手机漏检，因此此数字不用于宣称手机检出精度。手机不在的57个稳定采样仍有22/45/44个手机类别输出（R03/R04/R05），与物体角有关，语义误报结论待类别确认。

## 定位与已完成修复

对相同已缓存预测做一次事后诊断：仅去掉接触画面边界（距边≤1原图像素）的手机框，不改杯框/阈值/事件规则。三个模型的第二次missing均恢复至52秒；长杯片额外手机事件和空场片手机事件消失，杯事件不变。说明边界候选足以造成上述事件干扰。

这只是定位实验，不是训练改进、独立验收或正式过滤规则。用户已豁免部分出画手机的漏检，为可选可见性过滤提供了范围依据；正式采用前仍需验证完整可见手机不会被误排除、配置能回退。未据同片事后改善直接启用或更换默认模型。

已实现 `load_selection_manifest` 对冻结数据集与选优集的业务标签语义一致性检查（类别、bbox、iscrowd、重复数量），忽略无关类别和额外元数据。对应25项测试通过，真实R04的42条选优清单通过；Ruff及diff检查通过。未改变历史选优分数和权重。
