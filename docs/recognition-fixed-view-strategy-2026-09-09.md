# 固定视角透明杯：可用性判断与改进选择

日期：2026-09-09，Asia/Shanghai。此次是资料分析与存量证据复核，没有新开摄像头、训练或改变正式识别逻辑。

## 使用条件与结论

用户明确后续摄像头视角基本保持当前情况，这类杯子姿态也可能正常发生。因此当前视角、透明杯、靠近画面边缘等情况应纳入使用条件；上一轮等待用户改变摆放不再是推进前提。不能用要求用户只保留容易识别的姿态替代质量改进。完全遮挡时只可说明无法确认，不能从历史推断当前仍在或已离开。

通用小模型出现此类错误有技术原因，但当前表现不能视为已达到项目可用要求。没有可直接套用的统一“正常误检率”。需要同时改善首次识别、持续分类和事件可靠性。

## 已知事实与指标边界

证据沿用[新视角复验](cup-viewpoint-validation-2026-09-09.md)及[脱敏计数](../harness/evaluations/cup-viewpoint-20260909.json)，未新增实验结果。

| 当前正式配置、固定 118.592 秒窗口 | 观察结果 |
|---|---|
| 新鲜采样 | 119 次 |
| 输出杯子 | 83 次，采样命中 69.7% |
| 未输出杯子 | 36 次，占 30.3%；最长连续 8 次 |
| 错误消失事件 | 1 次；对应证据中杯子仍可见 |
| 摄像头故障 / Agent 运行 | 0 / 0 |

30.3% 是本段未检出采样比例，不是标准假阳性率。119 个相邻采样也不是119个独立试验。缺少全面逐框标注与明确负例分母，不能计算现场 FP/(TP+FP) 或 FP/(FP+TN)；这约两分钟的一次错误事件不能外推成稳定的每小时误报率，也没有证明通知实际发送。

RF-DETR 对当前视角三张原图均把杯子判成瓶子，分数约 0.884—0.912，说明高置信度不能担保类别正确；三张难例不能代表其总体错误率。第三遍翻转在30个偏置困难样本里新增0正确杯、1假杯；RF杯子补检新增2正确杯、1假杯。这些结果不足以支持部署，也不能当作日常误报率。

## 资料支持与工程判断

- 透明物体的反射、透射与背景混合会削弱外观线索；TransCues 研究专门利用边界与反射改善透明物体分割。该论文支持“透明物体是特殊难点”，不证明其模型能直接解决本项目杯/瓶分类或满足CPU预算。[论文](https://arxiv.org/abs/2512.07034)
- Frigate 对静止物体保留关联并周期重新检测，说明连续视觉系统需要跨帧管理与新鲜复核。借鉴这一原则不等于已实现可靠跟踪，也不能把预测框写成新识别事实。[官方说明](https://docs.frigate.video/configuration/stationary_objects/)
- YOLO26 官方提供预训练权重微调，并强调多角度、光照和背景的数据多样性，没有固定样本数保证。针对实际场景适配权重是值得优先验证的长期方向，收益仍须独立测试。[官方指南](https://docs.ultralytics.com/guides/finetuning-guide/)

## 建议顺序（尚未实施）

1. **先隔离不确定识别与消失事件。** 杯/瓶冲突、边缘缺失或复核不一致时，显示“暂时无法确认”；到缺失确认窗口先对当前新鲜图像做有界局部复核，周期全图检测仍负责发现新物品。历史最后确认时间保持真实，不能用旧框补检测。该方案需要明确增加不确定状态并修改事件契约；不是把五秒改成十秒，也不能只通过压制事件制造高正确率。必须同步统计真实移出漏报、延迟和不确定状态占比。
2. **在不训练约束内，验证局部类别复核。** 用同一新鲜图的候选区域区分杯、瓶与桶，保留拒识出口；复核只有在独立难例和负例上同时证明收益才采用。已失败的翻转、RF替换及既有YOLOE/MobileCLIP实验不重新包装成已解决方案。该路线可能改善部分错误，无法承诺当前所有杯子姿态都高检出。
3. **若允许改变“不训练”范围，优先做场景微调试验。** 收集实际视角的多种杯实例、透明度、杯柄方向、靠边/部分遮挡、照明变化，并加入瓶/桶等易混物与空桌负例；保留其他首版类别数据防止退化。开发与验收按日期、完整会话及物体实例隔离，不把邻帧拆入训练与测试。通过后才评估轻量模型ONNX本地部署。当前仅分析此选项，没有训练授权或训练结果。

## 后续验收设计

原固定光照、无遮挡、每类十轮放入/移出且事件正确率至少90%的目标保留，不能用它覆盖新增实际条件。增加当前视角的透明杯、靠边、部分遮挡和干扰物会话；独立记录杯在场时的错误missing、无杯时的错误appeared、真实移出/放回成功数与延迟，以及无法确认的时长。

初步筛查可使用跨时段的多个分离会话，至少覆盖真杯在场、空桌和易混物，不同杯实例留作验收。需要更长的代表性无动作观察才能估计低频错误事件，短测零错误不等于长期可靠。验收按条件分别报告，不能用容易场景平均数掩盖本次困难姿态失败。
