## 使用与边界

停止观察，选择1920×1080、完整画面，开启“忽略底部银色物体（固定机位）”后重新开始。默认关闭；环境变量为 `VAA_SILVER_OBJECT_IGNORE=false/true`。当前本机配置1280×720未自动改动，不能据此称当前运行页面已启用。

仅对2026-09-20已检查机位的底部小区域生效。候选必须是phone，框位于[720,960,1180,1080]内、中心x在[740,1040]内，且下沿距底边不超过2像素。保留其他触边手机及所有cup/bottle。这是空间排除，不是识别银色材质或物体身份；相机移动、该处放置别的物体时应关闭/重新标定。

请求非1920×1080或裁剪画面时禁止开启，避免区域错用。若摄像头实际返回其他尺寸，检测器保留原输出而不套用排除；需核对页面实际预览尺寸。开启后不能把真实手机放进这个指定忽略角落并期待被识别。

过滤器位于杯复查之后、VisionWorker之前，显示与存储使用同一输出。开关纳入运行设置及视角键；运行中更改须停止重开，切换重置事件基线，避免配置切换制造缺失事件。原始YOLO权重/未过滤实验结果保留。
