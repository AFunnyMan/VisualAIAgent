# 物品识别模型选择

侧边栏“物品识别模型”可选择原始通用 YOLO26n、固定场景 R03/R04/R05，或沿用配置文件。R03/R04/R05 是实验候选，未通过独立质量验收，选择功能不代表正式替换模型。

选择后点击“开始观察”生效；仅改变下拉框不会改变正在运行的模型。“待启用模型”和“当前实际启用”分别显示所选项与实际加载身份。停止后当前实际启用为无。启动前校验预设 SHA-256；文件缺失或校验失败会提示，不能冒充加载成功。

更换型号时先停止旧观察，重新构建检测器并重置事件基线，避免把模型切换造成的差异记录为物品移出。选择不写入 .env；服务重启默认仍遵循原配置。私人权重不随源码提交，其他电脑需单独准备对应文件。
