# 视觉记忆工作台界面

2026-09-21。按用户确认的浅色效果图实现，保留本地 Streamlit、现有业务服务和七个 Agent 工具。

## 页面入口

| 入口 | 内容 |
|---|---|
| 工作台 | 实时预览、当前物品、智能对话、最近物品事件与提醒 |
| 记忆 | 按物品查询最后观察、历史事件和按需加载的证据图 |
| 提醒 | 关注与提醒、情境规则两个按需执行的标签 |
| 行为统计 | 行为与有效时长、实验笔记本开合 |
| 设置 | 设备与模型、调用记录；实际连接与数据隐私说明 |

桌面下预览与对话约为 60:40；1000px 及以下改为满宽上下排列。侧栏支持折叠和重新展开，主按钮在每个页面顶部均可操作。视觉样式不改变取景比例或摄像头输出。

## 参数与状态

设备编号、清晰度、采样、物品模型、杯子增强、指定银色物体忽略、观察范围和实验模型入口均在设置页。选择保留在当前浏览器会话内，跨页和二级标签不会清空；点击顶部「开始观察」才应用。运行参数发生变化时先停止旧观察，停止失败则不重启；参数不变时复用运行实例。重启服务仍按原配置初始化，不写 `.env`。

新浏览器会话在已运行时优先显示实际加载的设置；待启用选择与实际模型分开展示。Agent「已配置」不等于请求已经连接成功。未知、断连、过期、实验模型和历史记录标识仍保留。

## 数据与刷新

- 工作台只显示真实本地数据；不填入效果图的演示物品、回答或事件。最近动态合并既有物品事件、关注通知和情境通知，最多三条；「查看物品记忆」进入物品历史，完整通知在提醒页。
- 当前物品按有效观察显示；过期或停止不会把历史框当成当前物品。置信度与性能信息进入识别详情，实际模型身份常驻。
- 预览 0.2 秒、事实与状态 1 秒、动态 5 秒刷新。仅当前页面及二级标签执行，离开工作台不再绘制预览。后台视觉持续运行。
- 对话等待时局部刷新，空闲不轮询；跨页保留 Future，返回后消费结果，不重复提交。图片仍需用户显式加载。
- 本地 CSS、系统字体和框架自带图标，不引入远程字体、前端 CDN 或新模型调用。

## 验证与边界

测试覆盖参数跨页保留、未应用不启动、模型切换、相同参数不误重启、断连/停止失败、创建取消提醒、证据按需加载、隐藏页不执行预览/统计、过期检测不显示、对话跨页单次提交。实际命令、浏览器尺寸检查与结果见 [进度记录](../harness/build-log.md)。

本轮是界面与交互改版，不替代识别精度、Windows 实机或真实云端 API 验收。实现入口为 `app.py`，观察参数适配为 `visual_ai_agent/ui_controls.py`，视觉主题为 `visual_ai_agent/ui_theme.py`。
