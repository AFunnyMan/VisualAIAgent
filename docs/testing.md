# 验证与验收

状态：测试体系尚未实现；本文中的软件命令是计划入口，不代表命令已存在或已通过。当前文档准备只做文件、链接、范围与 Git 检查。

## 三层验证

| 层 | 条件 | 内容 | 不能代替什么 |
|---|---|---|---|
| 离线自动测试 | 可安装的 Python 环境 | 状态机、数据库、工具、任务、额度、恢复；使用明确标记的假模型/假时钟 | 真实 API、真实摄像头 |
| 真实模型测试 | 用户提供的模型配置与 Key | 模型实际选择工具、读取结果、执行关注与取消，记录真实用量 | 物体识别质量 |
| 摄像头和平台 | 真实设备与目标 OS | 三类物品、故障、延迟、安装及持续运行 | 另一平台的实机验收 |

## 拟建立的入口

阶段 00 建立 `pyproject.toml`、uv 锁文件及 dev 依赖组；测试目录产生后配置 pytest 的 `live_api` 和 `camera` 标记。默认入口只运行离线测试，不依赖凭据，不尝试联网或打开摄像头。

所有命令的工作目录为仓库根目录：

```text
uv sync --locked --group dev
uv run ruff check .
uv run pytest -m "not live_api and not camera"
uv run pytest -m live_api
uv run streamlit run app.py
git diff --check
```

初始化阶段先生成并核验锁文件，之后才使用 `--locked`。尚无用例时，不能把 pytest 的零用例收集当作通过。真实模型测试独立执行，凭据缺失标注跳过，不在默认测试中偷偷运行。手工摄像头验收单独记录。

## 需求与场景

| 场景 | 对应目标 | 通过条件 |
|---|---|---|
| 三类物品放入、移出 | G01、G02 | 有检测、时间、区域、事件和可打开的证据 |
| 遮挡两秒 | G01、G02 | 无提前缺失事件 |
| 多个同类、未知类别、无历史 | G02、G03 | 展示候选或未知，不虚构身份与位置 |
| 自然语言最后位置查询 | G03 | 真实模型调用查询工具，答案引用结果 |
| 自然语言创建/取消关注 | G03、G04 | 任务真实持久化、取消生效，回复与执行一致 |
| 十分钟无相关事件 | G05 | 模型调用计数不变，观察仍正常 |
| 相关事件与重复投递 | G04、G05 | Agent 复查状态，只有一条有效提醒 |
| 提醒前取消/到期 | G04 | 阻止迟到工具写入 |
| API 超时/非法参数/用量缺失 | G03、G05 | 可见错误或降级；用量不伪装为零 |
| 模型/每日自动调用额度耗尽 | G05 | 停止额外自动调用，本地事实继续记录 |
| 断连、暂停、过期画面 | G01、G02 | 标为未知，不解释为物品消失 |
| 重启恢复 | G02、G04 | 历史及未过期任务恢复，不推测停机事件、不重复通知 |
| 证据保留和清理 | G02 | 普通数据按策略清理，最后观察证据与引用完整 |
| UI 重运行、启动、停止 | G07 | 不重复打开设备/启动线程；正确释放资源 |

核心逻辑使用假时钟加速边界测试，十分钟真实等待和三十分钟稳定性另作实测；不得把加速模拟写成真实时长运行。

## 识别质量

固定光照与拍摄位置、无遮挡条件下，每类物品十次放入和十次移出，放入/移出间保留足够确认时间。逐条记录预期事件、实测事件、额外误报、漏报、区域和证据。事件正确率定义为正确匹配的预期事件数除以预期事件总数；额外误报数量单独报告，不能被比例掩盖。总体及每类目标均至少 90%，并保留失败样例。截图只能在本地保存或经脱敏后作为可分享材料。
