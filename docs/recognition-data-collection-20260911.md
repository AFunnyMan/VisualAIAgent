# 固定场景识别补拍清单

2026-09-11，Asia/Shanghai。用户重新授权性能专项、物品识别优化，并新增钥匙与被观察笔记本合盖训练。自定义区域、手机使用时长和额外可靠性扩展仍暂缓。本文是首批采集与实验安排，不是已训练或质量通过报告。

## 本次问题与处理顺序

用户报告躺靠椅子被判断为站起。现行姿态分类器为 seated/standing/empty，另有低置信拒识；人体框关联只提供连续性支持，不直接验证坐站。需要区分错误的 standing 状态与实际 stood_up 事件。本轮没有对应时点的逐帧证据，不能断言具体失败原因。优先假设是正常躺靠姿态覆盖不足，需新样本验证，不能通过降低门限或延长确认时间宣称修复。

1. 新视频按完整录制分组：开发训练、开发验证、独立验收；冻结文件哈希。旧开发片回归，不再当独立测试。
2. 躺靠、侧靠、前倾统一属于在座；保留站立、空座及不可判断。先以新旧在座/站立样本混合重训对照，再评估局部人体输入或可见关键点辅助。关键点不可见时拒识，不硬推姿态。
3. 钥匙新增检测类别并标框；与杯、手机、瓶的既有样本联合比较，验证小目标与易混物。不要求补拍瓶子。
4. 笔记本单独研究打开/闭合/中间或不可判断状态。开盖黑屏仍属打开；漏检、遮挡或移出不算合盖。只有连续确认打开到闭合才产合盖事件，启动已闭合不补事件。
5. 接入既有七工具和时间/区域规则，做真实钥匙＋合盖提醒。无合格模型时选项继续不可用。
6. 复用旧性能证据定位主姿态、编码、复制/哈希长尾，评估共享处理及有界发布；记录p95/p99/最大延迟、过期率、内存和动作遗漏，不放宽250ms保护来消除失败统计。

## 拍摄方式

- 使用最终固定USB机位的原始视频，尽量保持当前1920×1080，原生帧率即可，不必升到60fps。不要录带识别框的网页或裁剪/加速视频；mp4/mkv均可。不需要录声音或提供新模型。
- 使用日常椅子、衣服、杯子、手机、钥匙和被观察笔记本。保持真实躺靠幅度、真实摆放，不必把物品刻意摆得更容易识别。不要求换人换场景。
- 每个稳定姿态/摆放停5—10秒，完整保留转换过程。钥匙或笔记本完全被挡时也要保留，标注将视情况记未知。
- 下表是首批开发素材建议量，不保证拍够这些就达标。拍完停录，另拍独立验收，不从同一连续视频相邻帧随机拆训练与测试。

| 文件建议名 | 拍摄内容 | 首批开发量 |
|---|---|---|
| 01_在座变体 | 正坐→刚才出错的躺靠→坐直；左右侧靠、前倾拿桌面物品、伸懒腰、调整椅子但不离座 | 2—3分钟，正坐/躺靠往返至少6轮，各姿态停5—10秒 |
| 02_真实坐站离座 | 坐5秒→站3—5秒→坐5秒，至少6轮；另做起身→离开画面5—10秒→返回坐下至少4轮；加入站在椅子旁、弯腰拿物 | 2—3分钟，保留快慢自然转换 |
| 03_饮水及反例 | 杯口到嘴至少6次；拿杯靠脸但不到嘴、拿杯查看、摸脸、擦嘴、托腮各若干次，放杯间隔5秒；可包含躺靠举杯 | 2—3分钟，不要求实际吞咽 |
| 04_钥匙 | 实际携带的整串钥匙，左/中/右常用位置、正反面和不同朝向；每次放下停5—10秒，再拿走；加入部分遮挡和靠边 | 2—3分钟，约12次不同摆放，拍到有/无钥匙 |
| 05_笔记本开合 | 打开停5秒→完全合上停5秒→再打开，至少8轮，包含快慢合盖；补开盖黑屏、半合停留、仅调屏幕角度、手遮挡、移开笔记本 | 3—4分钟；至少4轮不合盖的反例，合盖边缘应在机位中可观察 |
| 06_杯与手机难例 | 现用杯不同朝向/靠边/部分遮挡；手机平放、斜放、屏幕亮灭，与杯相邻；逐次放入移出，中间停5秒 | 2—3分钟；瓶子维持免补拍 |
| 07_正常无目标动作 | 正常坐着/躺靠、打字、挠头、取物；不真正起身或合盖；另一段空座，可留衣物在椅子上。桌上可摆笔、线、遥控器等易混物，部分时段无钥匙 | 5—10分钟，主要估计额外事件，短片不能证明长期误报率 |

可分批提供，优先01、02、04、05。以上总开发录像约18—29分钟，允许拆成多个短文件。

## 单独的验收录像

另起录制，文件名前加 `验收_`：

- 在座变体与躺靠、坐站、离座返回、饮水与反例，约3—4分钟。
- 新的钥匙摆放＋笔记本开合与反例，约3—4分钟。覆盖钥匙在/不在、只有手遮挡、只有黑屏；真实18点条件最后可以现场验证，无需等18点拍训练视频。
- 正常活动及空座约3—5分钟。

无需换天，但必须是另拍的动作，不复制开发视频。验收素材不用于调参；若验收失败并用于改进，该片降为开发素材，下轮重新补独立验收。
