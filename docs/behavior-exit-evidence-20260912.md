# 离座退出边缘证据修复（2026-09-12）

## 问题与约束

姿态 r04 在已冻结的 176.7 秒验收片上稳定状态 1699/1699 正确，但动作仅 4/5：118.4 秒已确认站立，118.8 秒分类变为 `unknown` 且人体关联因多候选中断，119.3 秒确认空座时站立前态已按保护规则清除，因此没有 `left_seat`。该视频在本次状态机修复中已经曝光，以下复跑只属于诊断回归，不构成新的独立验收。

修复不能把未知、遮挡、断流或历史状态直接解释成离座。实现因此没有放宽分类拒识或故障保护，也没有将人体消失本身当作离开。

## 实现

`SeatPersonGate` 保存最近 0.5 秒的已关联人体中心轨迹。只有轨迹在连续有效帧中至少移动归一化距离 0.04，并到达画面边缘 0.03 范围内，后续最多 0.8 秒才输出独立的 `exit_evidence`。无候选可使用该证据；多个匹配候选只有全部位于轨迹实际指向的同一退出边缘，且高度重叠、近似嵌套为重复检测时可使用。仅共享其他边缘或同边缘出现两个相邻人体均会拒绝。静止贴边消失、空间不匹配、候选指向不同边缘、无效帧、尺寸变化、逆序时间和超过采样间隔均会拒绝或清除证据。

`BehaviorTimelineV2` 只在旧确认姿态为 `standing`、新姿态为 `unknown` 或 `empty`、画面新鲜且无时间故障时使用 `exit_evidence`。它只保留完成 `standing → empty` 所需的有界前态，不作为 `continuous_visible`，不延续饮水，不补造站起/坐下，也不允许坐姿直接借此产生离座。

正式 `BehaviorWorker` 和离线回放均传递该独立字段。同期修正 `BehaviorWorker` 的 observation/event 来源，使用底层共享源的 `source_name`，使视频回放保留 `replay` 来源而不是硬编码为 `camera`。
