# 阶段 01：真实工具调用 Agent 核心

## 目的与前置条件

目标 G03、G05。接入单一 VisualMemoryAgent，使自然语言能驱动工具并根据结果回答。阶段 00 的环境和配置接口已验证。实际进度见 [build-log](../build-log.md)。

阅读 [架构与七个工具](../../docs/architecture.md)、[测试](../../docs/testing.md)、[复用来源](../../docs/references.md)。

## 范围与接口

实现业务工具签名、ToolResult 和 Agent 适配层。视觉/记忆用可替换的模拟服务，明确标注模拟来源；不会把模拟观察写入未来生产视觉数据库。此阶段不访问真实摄像头，不声称完成视觉记忆或自动事件提醒。

## 实施步骤

1. 参考 Agents SDK 的工具、会话和用量示例，使用普通 Agent/Runner，不接入 Shell、代码执行或多 Agent。
2. 实现七个带类型和参数校验的工具边界，以及供测试注入的业务服务。查询、创建、取消的回复必须以真实工具返回为依据。
3. 用假模型与明确标记的模拟视觉记录验证循环、工具失败、任务重复请求及未知结果。此层用于可靠回归，不承担真实模型验收。
4. 配置实际模型适配、有限超时、三轮模型请求限制、关闭网络自动重试、上下文截断及用量记录。无 Key 清楚返回 Agent 未连接。
5. 凭据具备时执行小规模真实 API 测试，观察查找、创建、取消与无记录场景。记录模型版本、请求次数和用量，不记录秘密。

## 验证与验收

建立 tests/agent 下的离线用例和独立 live_api 用例。计划命令：`uv run pytest tests/agent -m "not live_api and not camera"`；真实验证使用 `uv run pytest tests/agent -m live_api`。这些命令需随实际目录创建后核验。

通过条件：真实模型选择工具并读取结果，非法参数不会产生写入，达到调用限额后不继续请求，无配置零云端请求。真实调用证据与假模型结果分开。

## 恢复与后续交接

无凭据时保持真实验证未完成，记录阶段为进行中或阻塞；已验证的离线接口可交付阶段 02—05 使用，但不能宣称阶段 01 全部完成。阶段 03 替换模拟记忆服务；模拟数据与逻辑不得成为生产数据。失败不自动反复调用付费服务。决策入 context，实际结果入日志，审查后提交当前已授权的可验证里程碑。
