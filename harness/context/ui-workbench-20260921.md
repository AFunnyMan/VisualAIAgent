# 工作台界面改版上下文

2026-09-21，Asia/Shanghai。用户先要求分析高级感排版，随后确认生成的浅色工作台效果图，并授权按图实施、完成测试。

- 延续 Streamlit 和现有单 Runtime，不增加前端框架、云端上传或业务工具。首页为实时预览/当前物品与对话双栏，最近动态在下；侧栏按工作台、记忆、提醒、行为统计、设置组织。
- 设备、模型、区域与实验开关移入设置；工具栏全局保留开始/停止。未应用偏好放在独立会话字典，控件使用锁定的 Streamlit 1.63 `persist_state="session"`，跨页不丢失。点击开始才应用；实际模型和待启用选择分开展示。
- 保留预览 0.2 秒、当前事实/状态 1 秒、最近动态 5 秒刷新；只渲染当前导航及当前二级标签。闲置对话不设定时器，证据仍需主动加载。停止/断连/过期不显示旧检测为当前物品。
- 效果图中的桌面、回答、时间与事件是示例，不写入真实页面。空数据给空状态，真实记录按原来源显示；不以美化替代未完成的识别质量或平台验收。
- 样式经实际浏览器 DOM 核对：主容器为 `stMainBlockContainer`，主双栏位于 keyed container 的直属 `stLayoutWrapper` 内；仅调整本项目容器，避免影响行为统计内部列。
- 初次热加载触发旧资源锁占用，采用正常停止旧服务后启动新版本解决，未删除数据库或锁文件。模型/阈值及配置文件不因界面任务更改。最终结果见 [实际进度](../build-log.md)。
