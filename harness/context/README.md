# 阶段上下文

此目录只保存阶段实施中影响后续工作的决定、发现、约束和未解决事项。当前是文档准备，没有业务阶段开始，因此不预先创建阶段上下文文件。

阶段真正开始时创建 `phase-<NN>-<slug>-context.md`，写明阶段与关联计划。每条重要记录包含时间及时区、事实或决定、依据、原因、受影响的接口/验收/后续阶段。被替代决定保留并指出替代项。

不要复制原计划、逐条工具输出、整段聊天、例行进度或秘密。实际执行状态归 [build-log](../build-log.md)，审查归 [code_review](../code_review/README.md)。链接规范来源，不制造多份事实。

恢复工作先阅读阶段计划、日志和相关 context，再检查实际代码。没有 context 文件表示阶段未开始或尚无相关记录，不得据此猜测功能已经存在。
