# 行为、统计与情境规则正式集成

2026-09-11，Asia/Shanghai。用户批准本轮实现计划，并明确调整优先级：暂缓主处理/发布长尾专项、物品识别质量与训练、自定义语义区域、钥匙/合盖检测和其他可靠性增强。先接入现有实验行为模型、有效时长统计、休息提醒与现有物品/区域的基础情境规则。手机使用识别延后。

## 实施边界

- 单摄像头、单 Agent、原七业务工具；物品与行为分别按现有频率处理共享画面。
- 不重新训练，不修改原阈值或取消250ms行为新鲜度保护；模型仍标实验，不将接入页面当质量通过。
- 姿态与疑似饮水独立表达；在座不代表学习/专注，杯口到嘴不证明吞咽或饮水量。
- 时长只来自连续有效区间。未知/故障中断连续计时，但已触发休息提醒资格只在确认离座后恢复，防短暂未知重复提醒。
- 基础规则为行为事件触发时检查时间与物品区域条件。只采用触发前已存在、同场景且有效稳定的事实。物品候选不是身份；提醒标明触发时观察。
- 规则默认长期有效，可修改/启停/取消；同规则版本同事件只通知一次，排队旧版本失效。休息提醒默认关闭，建议45分钟可改。
- 仅页面提醒，钥匙/合盖未支持，自定义语义区域未开放。不自动建立示例规则。
