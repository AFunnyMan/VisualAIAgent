# 工作台界面改版审查

2026-09-21，Asia/Shanghai。独立 Sol 只读审查模型切换、会话参数、Future 去重、过期保护、隐藏页执行与 HTML 转义。

## 发现与处理

- 「最近动态／查看全部」实际只到物品历史，不能展示全部提醒：改为准确的「查看物品记忆」，完整通知仍在提醒入口。
- 队列数量和自动调用日上限在布局重排中丢失：恢复至设置／调用记录。
- 根审查发现行为与笔记本运行配置包含非 UI 字段，完整元组直接对比会误重启：仅比较 UI 控制的前三/前二项，新增完整元组的跨页不重启用例。
- 浏览器发现初稿依赖的容器名称与实际 Streamlit 1.63 DOM 不符，字号与间距未生效：按实测容器、布局包装和 radio 结构修正；不使用散列 CSS 类。
- 窄屏下桌面 `:first-child/:last-child` 的样式优先级覆盖满宽规则：统一优先级后复验主面板满宽。占位画面额外限制盒模型与宽度，避免裁切。
- 隐藏整个框架工具栏会连带隐藏侧栏展开按钮；恢复后透明工具栏又遮挡主按钮：改为仅隐藏部署等无关控件，并禁用透明容器指针事件，保留展开按钮交互。
- 浏览器发现对话片段内快捷按钮只改变会话导航而未重画页面，AppTest 全页执行未暴露此问题：增加片段导航请求标记并显式执行全应用重绘，真实浏览器复验「查找物品」「设置提醒」均切到对应页面，侧栏同步选中。

未发现业务工具数、真实模型调用、事件语义、预览跟踪或数据库接口被本轮变更扩大。验证结果及实测限制见 [进度](../build-log.md)。
