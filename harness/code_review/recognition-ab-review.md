# 识别策略实验审查

2026-09-07，Asia/Shanghai。主Agent及三个Sol子Agent完成对照与只读复核。结果见 [实测报告](../../docs/recognition-ab-results-2026-09-07.md)。本轮新增评测脚本与证据，不将候选写入生产。

## 已修正事项

- YOLOE的PT默认矩形padding与静态ONNX不一致，通用ONNX wrapper的默认NMS也与YOLOE wrapper不同。旧输出归档为rect-auto；统一640方形输入、显式agnostic NMS后重跑488帧、30图和53帧导出对照。没有放宽计分阈值。
- CLIP单个crop的导出比较不足以证明级联一致性；扩为全部123个真实候选，原PT/重参数化PT/ORT核验，接受决定不一致0。首轮benchmark误带额外文字塔的RSS不采用，纯图像塔+缓存文字的独立进程重新实测。
- 最初检测器导出比较用了旧拼图JPEG，保留为montage-validation；另用原始顺序解码帧完成20组正式比较，避免把拼图能力误当原画面能力。
- 候选列表每类前10的上限可能截掉高分密集瓶；时序实验明确保留全部基线高分检测，仅低分诊断候选有界，不通过截掉基线检测改变比较。
- 评分器强制唯一manifest/预测ID且集合完全相等；新增缺图、重复manifest、重复预测、错误类别、定位不符和crowd用例，防止分母无声变化。

## 独立核对

- 30图推理前固定seed选择，全部原始标注保留；三类分母为23瓶/20杯/9手机。四份原检测器分数经Sol重新计算一致，主Agent再从仓库归档预测复算五检测器/四复核组合，分类统计全部一致。
- 488采样时点与帧索引在五个检测配置间一致，n端到端的检出帧数与此前基线逐视频完全复现；30图哈希重新核对。
- Sol逐图复核四模型rice/beer拼图，主Agent查看杯子、工业场景、YOLOE失败点。抽取s传统头4个FP，发现定位失配、真实杯状物/烛台类别歧义或疑似漏标；未修改GT。报告不把FP全部称为纯背景误报。
- 低分关联框必须来自当前帧，不能无检测复制旧框；低分不刷新高分锚点，最多维持2秒。新增出现事件仍可能不可靠，该模块只作为诊断，不能直接刷新生产last_seen。
- 所有模型推理停止后按四检测器→YOLOE→CLIP顺序、独立进程计时。报告区分完成后RSS采样、结束RSS与进程峰值，不把短微基准说成应用稳态CPU/30分钟/Windows实测。
- MobileCLIP代码MIT不代表模型可产品使用。读取并核验Apple官方模型许可，研究用途排除产品开发；该权重不纳入产品，YOLOE文本编码器许可链亦需单独核验。

## 结果与未关闭项

Ruff、格式和本机离线回归100 passed、3 deselected；新增8个有意义的计分/时序失败用例。导出实验独立于生产环境、uv.lock与模型manifest，未调用百炼/USB或训练。模型二进制、来源图片、隔离环境、.env和完整日志被忽略。

没有候选全面胜出；新策略没有达到三类现场≥90%的验收证据。生产配置、三次/五秒契约、七工具和单Agent保持当前版本。USB、Windows11实机、候选模型持续运行及识别质量问题继续开放。远程CI状态只在实际返回后写build-log。
