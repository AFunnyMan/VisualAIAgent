## 发现及处理

- 显式全幅`--region 0 0 1 1`被当作“自定义裁剪”展示：CameraSource与Config现统一全幅为None，回归验证完整输入不裁剪且原始对象透传。辅助台摘要/文案因此与CLI约定一致。

- 初版页面用整数百分比舍入配置，可能改变有效ROI或导致极窄范围越界：改浮点百分比控件，AppTest覆盖0.1234等小数配置和停→启参数透传。
