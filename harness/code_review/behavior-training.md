# 固定场景行为试训审查

2026-09-09，Asia/Shanghai。开发及独立审查子Agent均为GPT-5.6 Sol；root复核关键代码、源视频拼图和训练执行。

## 已处理问题

- 普通分类目录检查只能阻止同图跨split，无法阻止同源视频不同帧跨split。普通训练/验证模式现在要求源组manifest、核验每张图SHA及所属split，并拒绝同源组跨train/val。首轮实际仅train，不伪造val。
- 输出目录先检查再创建存在竞态；现原子预留放在异常写清单逻辑之外，失败时不写未知目录。
- 分类器默认随机裁剪可能截掉杯口/面部。全画幅等比填充变换可序列化，训练仅小幅颜色扰动，验证及ONNX输入使用同一几何/RGB/归一化代码。默认翻转、擦除关闭。
- Ultralytics初始化需要val loader但当前无独立验证集。首轮明确train-only、val=False、覆盖validate/final_eval、固定最后一轮导出；训练日志“val images”是占位初始化，不是质量验证。
- ONNX只导出不能视为验证：新增独立评估工具核验SHA、类别元数据、静态FP32输入/输出及概率语义，并在真实执行时要求相同输入PT/ORT分类一致及maxabs≤1e-4。执行结果见训练日志。
- 空座分类与饮水输出可能矛盾；空座/未知人体证据不能确认饮水事件。时间跳变、断流与unknown中断动作连续性。坐着与饮水可同时成立，站立单帧不等于起身。

## 保留限制

- 三段均为训练素材，仅两次饮水、少量短站立片段。所有重放属于开发数据复测，不是独立动作准确率或实机验收。
- 时序仅实验内存状态，未连接正式通知和持久化业务；不把实验边沿去重宣称为产品通知幂等验收。
- 过渡状态可能被置信度门限拒识而漏掉起身；不能为消除漏报把未知直接改成离座或站立。回放须如实记录漏事件与误事件。
- 正式物品模型、环境配置、三类接口和七业务工具未被本轮替换。Windows行为模型实机、摄像头实时行为准确率尚未验证。
