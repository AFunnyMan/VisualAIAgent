## 已发现并修复

- 生产模块依赖scripts且推理重复：实现迁入visual_ai_agent，旧脚本兼容导入，保留原阈值与有界推理参数。
- 共享相机慢打开时物品消费者提前退出：新增350ms打开测试，真实USB复测双分支均有fresh。打开错误保留，未清理线程保留引用与实例锁。
- 行为事件确认时间与存储契约冲突、JPEG后缺新鲜度检查：采用原始采集时间，在推理/发布边界再次检查。停止立即持久化同场景unknown。
- 按每帧新增永久区间：相同区间合并更新；未来、回拨、断流不补在座，会话内可信长gap计未知。
- 物品条件跳过故障或跨场景：检查最近三条完整记录、同场景会话/来源、原物品采样容差与触发前提交边界。
- 行为计时错误复用物品容差：独立250ms；持久化阈值跨越资格，未知不重复提醒，确认空座才重置。计时证据保存连续起止、实际秒数与阈值。
- DDL隐式提交及v3不完整：行为/规则表和版本事务提交，缺关键表列拒绝启动，升级前备份。
- fallback只生成文字：改从持久化任务读取，经去重/版本检查写入本地降级通知。
- 重复投递可能同时模型请求和降级：增加原子queued→processing领取，失败不请求模型。
- Agent局部更新覆盖默认字段：受控patch，明确移除条件参数，测试验证仅修改时间时保留其余字段。
