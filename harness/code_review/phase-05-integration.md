# 运行时与页面集成审查

2026-09-07，Asia/Shanghai。root 审查并修复，Sol SDK 子 Agent 独立复核了生命周期、工具边界和界面模型唤醒路径。

已修复：

- fragment 内主动 rerun 在整页执行中不合法；改为兼容两类执行上下文的 st.rerun，并用创建/取消回归验证。
- 重启时丢弃 recover 返回的 processing 任务；现在只重入未完成的已匹配事件，已提醒的任务不重复处理。
- Config 的模型路径与实际导出名不一致、校验值未传递；统一 e2e 文件名并将配置 SHA 传至检测器。
- SDK 客户端需在后台 asyncio loop 关闭前释放；加入限时 async close。若工作线程未退出，保留进程锁，不能立即启动第二实例。
- 仅启动时清理不足以实现长期保留策略；运行时每小时清理一次，清理失败可见。
- 切换采样档必须同步调整允许间隔并重置连续确认；重新启动模型复用，worker 不重复创建。
- 离线测试不能取决于项目是否恰好有模型/.env；缺模型测试用临时路径，离线 fixture 用空配置阻止 dotenv 引入真实 Key。
